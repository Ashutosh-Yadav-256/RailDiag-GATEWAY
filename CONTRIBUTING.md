# Contributing

1. Open an issue/change request with the requirement IDs affected.
2. Create a focused branch and make a small, reviewable change.
3. Add regression/integration tests and update `docs/traceability.csv`.
4. Run the CMake build and complete Python test suite.
5. Update the architecture, safety/hazard or interface documentation when behavior changes.
6. Request peer review before merging.

Never describe this demonstrator as railway-certified, SIL-rated, EN 50716-compliant or IEC 61375-conformant. Never connect it to real train equipment.

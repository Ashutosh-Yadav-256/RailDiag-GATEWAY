# Resume wording guidance

Only use bullets that match code you have actually run, understood and can explain. At this baseline, defensible wording is:

**RailDiag Gateway — Linux Onboard Diagnostics Demonstrator** | C++17, POSIX Sockets, Python, IEC 61131-3 Structured Text, CMake, unittest

- Built a C++17 Linux telemetry gateway using POSIX TCP sockets, concurrent client workers, input validation and per-device sequence checks.
- Implemented diagnostic classification for synthetic temperature/voltage events, structured JSON responses and CSV event logging; verified behavior with Python end-to-end tests.
- Authored a Structured Text diagnostic example and V-model artefacts covering requirements, architecture, preliminary hazards, verification planning and change control.

Do **not** claim TRDP/IEC 61375 implementation, EN 50128/EN 50716 compliance, SIL capability, certified railway software, or IEC 61131-3 toolchain verification until those items are genuinely implemented and independently verified.

# IEC 61131-3 example

`VehicleDiagnostic.st` contains a small Structured Text program expressing the same illustrative temperature/voltage status logic as the C++ gateway.

To experiment with a MATIEC toolchain, install/build MATIEC separately and compile the file with the toolchain's documented command. Toolchain versions and exact invocation differ. The project does not vendor MATIEC or claim conformance testing of the generated code.

The thresholds are training values only. Do not use this example to control real rolling stock or any safety-related equipment.
